4 · Screens per breakpoint

Breakpoints are container queries on .app: desktop ≥ 1080, compact 860–1079 (icon-only sidebar 72 px), phone < 860 (tab bar, 6 items, 56 px + safe area). Page max width 1040 px, centered, on every page; forms max 720 px, left-aligned. scrollbar-gutter: stable stops content jumping between pages.
