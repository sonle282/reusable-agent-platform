Mr Spa Admin, in the OpenAI design language

Look and feel follow openai.com/brand: minimal white and light gray, bold black type, black pill buttons, pastel blocks and soft gradients. Components follow OpenAI’s Apps SDK UI (MIT) so they match ChatGPT. No OpenAI logos, names or the proprietary OpenAI Sans font are used — Manrope stands in.
